# 사주구조대

어려운 말 없는 무료 사주. 생년월일을 넣으면 사주를 계산해서 명리 용어 대신 알아듣는 말로 진단해 줍니다.

**바로 쓰기 → https://good-saju.github.io**

## 이런 앱입니다

기존 사주 서비스는 일간이니 십신이니 하는 용어부터 나옵니다. 무슨 말인지 모르니 결국 해석해 주는 사람이 필요하고, 그러면 돈이 듭니다.

사주구조대는 계산은 똑같이 하되, 결과를 일상 언어로만 보여줍니다. "일간이 己土라 재성이 약하다" 대신 "남 부탁을 못 거절한다, 그게 착해서가 아니라 거절한 뒤가 불편해서다"라고 말합니다.

## 무엇을 알려주나

생년월일과 태어난 시간을 넣으면 다음을 보여줍니다.

- 내 유형 배지와 한 줄 진단
- 타고난 기운 (다섯 기운의 균형을 막대로 표시)
- 타고난 성향
- 돈 버는 방식
- 자주 하는 실수
- 오늘은 어떤 날 (매일 바뀜)

태어난 시간을 모르면 세 기둥으로만 계산합니다. 시간을 몰라도 결과는 나옵니다.

## 특징

가입, 로그인, 결제가 없습니다. 입력한 생년월일은 어디에도 저장되지 않고 사용자의 브라우저 안에서만 계산됩니다. 서버로 전송되는 데이터가 없습니다.

양력과 음력을 모두 지원하며 음력은 윤달도 선택할 수 있습니다.

결과 아래 "내 사주 원문 보기"를 펼치면 계산된 네 기둥과 기준 글자를 확인할 수 있습니다. 명리를 아는 분이 검증할 수 있도록 열어 둔 부분입니다.

## 기술 구성

HTML 파일 하나로 동작합니다. 빌드 과정이 없고 프레임워크를 쓰지 않으며, 서버도 데이터베이스도 없습니다.

사주 계산은 율리우스 적일 기반의 60갑자 순환으로 일주를 구하고, 절기 기준으로 연주와 월주를 정합니다. 시주는 한국 표준시와 실제 태양시의 32분 차이를 보정해 계산합니다. 음력에서 양력으로의 변환은 lunar-javascript 라이브러리를 사용합니다.

해석 텍스트는 40개 항목을 미리 작성해 두고 계산 결과에 따라 조합합니다. 실행 중 외부 API를 호출하지 않으므로 방문자가 늘어도 운영 비용이 발생하지 않습니다.

## 로컬에서 실행하기

저장소를 내려받아 index.html 파일을 브라우저로 열면 그대로 동작합니다. 별도 설치 과정은 없습니다.

## 알아 두실 점

절기 날짜는 근사값을 사용하므로 절기 경계일에 태어난 경우 하루 차이가 날 수 있습니다. 밤 11시부터 새벽 2시 사이 출생은 해석 기준이 갈릴 수 있어 결과 화면에 안내를 표시합니다.

## 면책
